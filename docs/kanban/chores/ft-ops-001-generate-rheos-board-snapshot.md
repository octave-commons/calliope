# FT-OPS-001: Validate cards and generate Rheos board snapshot

## Outcome

A local harness with eta-mu/Rheos validates the card corpus and creates the
generated `docs/kanban/board.json` snapshot.

## Scope

- Run board count/list/find validation.
- Correct schema or transition errors in source card Markdown.
- Generate `board.json` through Rheos.
- Record exact commands/results and Receipt River evidence.

## Non-goals

- Hand-editing `board.json`.
- Changing ADR or product design boundaries.

## Acceptance criteria

- Rheos reads `openhax.kanban.json` and all cards without error.
- Card IDs, dependencies, categories, and statuses resolve.
- `board.json` is generated by the tool and committed.
- Actual tool/version and output are recorded.

## Verification

```bash
eta-mu kanban count --tasks-dir docs/kanban
eta-mu kanban list --tasks-dir docs/kanban
eta-mu kanban board snapshot --tasks-dir docs/kanban --out docs/kanban/board.json
```
