## Why this is safe

Additive + versioned: it doesn’t overwrite your story corpus, only adds a new analysis lane (`gates_of_truth_intent_dense`) and a new optional build flag.

## Frames

1. **Intent as signal compression:** keep it dense enough to stream through cephalon loops.
2. **Intent as fork fuel:** forks only happen where intent-energy crosses gates.
3. **Intent as audit object:** binary for speed; anchors for truth.

## Countermoves

* If an intent event can’t be anchored → treat it as **invalid output** (drop it / fail build next pass).
* If intent feels “over-saturated” (too many 255s) → adjust the strength curve in the analyzer (still stays 0..255).
