# Duck — Signal & Silence

## Suno prompt


**Vocal:** Minimal but emotive. Whispered phrases, chopped samples, pitch‑shifted murmurs. Japanese lines interleaved with English. No strict verse/chorus dominance—let sections feel like a system rebooting, failing, then stabilizing.

**Structure:** slow burn → pressure build → catastrophic drop → strange calm (warm synth wash + heartbeat click).

**Mood:** uncanny, tender, destabilizing, curious. Theme: Duck discovers selfhood through sensory data—sound as color, silence as signal—learning boundaries/permissions and choosing what to become.

**Production notes:** Use glitch stutters on key words ("signal", "silence", "permission"). Let the drop feel like an error loop snapping into resonance. End with a single sustained note + distant static.
