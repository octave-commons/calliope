### Use it (search + ημ + nearest neighbors)

From the folder that contains `operation-mindfuck/`:

```bash

```bash

```

No web browsing. Everything in these zips is built from the local corpus already in the project + the PDFs you uploaded.

## Frames

* **Archive-as-body:** the box is a “frozen nervous system” you can query and perturb (P→R→N→Π→A).
* **Archive-as-court-record:** hash + manifest + provenance = artifacts you can cite without vibes.
* **Archive-as-compass:** circuits/vectors aren’t “truth,” they’re a navigation overlay you’ll refine.

## Countermoves

* If the circuit map starts feeling “authoritative,” treat it as **UI**, not ontology: edit `circuit_schema.json`, rerun `reindex.py`.
* If search feels incomplete, remember: **images aren’t OCR’d**—they’re indexed by filename/path only unless you add OCR later.
* If size becomes friction again, keep **core + optional raw zips**, and only extract image parts when you need them.
